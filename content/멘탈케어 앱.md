## 개요

걱정상자 앱 기획을 위한 해외/국내 멘탈케어 앱 6종 비교 분석.
각 앱의 핵심 특징, 타겟, 수익 모델, 규모를 정리, 적용할 수 있는 인사이트를 도출한다.

## 1. Finch (미국)

### 기본 정보

| 항목   | 내용                       |
| ---- | ------------------------ |
| 출시   | 2021년 5월                 |
| 다운로드 | 월 70만 다운로드 (iOS+Android) |
| 월 매출 | 월 200만 달러 (약 26억원)       |
| 타겟   | Z세대, 셀프케어에 관심 있는 20-30대  |

### 핵심 메커니즘

```
사용자 → 셀프케어 미션 완료 → 새(Birb) 성장 → 정서적 유대 → 지속 사용
```

### 주요 기능

- 캐릭터 육성: 새(Birb)가 사용자와 함께 성장
	- 일정 미션을 완료하면 Birb 가 모험을 떠나서 N 시간 후에, 전리품과 함께 돌아옴
	- 전리품에 따라 Birb 가 다른 질문들을 던지고, 사용자가 답하는 것에 따라 Birb 의 characteristics 가 변함
- 캐릭터 꾸미기: Birb 에게 옷을 입히거나, 집을 꾸밀 수 있음
- 셀프케어 미션: 물 마시기, 산책, 호흡 등 작은 미션
	- 미션의 완료 여부를 사용자에게 맡김
- 소셜 기능: 친구 초대, 함께 돌보기
- 저널링: 감정 일기 기록

### 차별화 포인트

- 구체적인 예시를 제공하고 한 번에 하나의 질문만 함
- **죄책감 없는 설계 (완벽한 날을 요구하지 않음)**
- TikTok에서 3배 높은 engagement
- 70%의 소비자가 동료 추천을 신뢰 → 앰배서더 전략

### 수익 모델

| 모델      | 가격                |
| ------- | ----------------- |
| 무료      | 기본 기능             |
| 프리미엄 구독 | $4.99/월, $34.99/년 |
| 평생 이용권  | $69.99            |

### 성공 요인

1. **캐릭터 애착: 사용자가 새를 "돌봐야 한다"는 책임감**
2. TikTok 바이럴: 사용자 생성 콘텐츠 + 앰배서더 전략
3. 극도의 간편함: 복잡한 입력 없이 탭 몇 번으로 완료


- 음악/사운드: 수면, 집중용 배경음

| Calm | Headspace |
|------|-----------|
| 명상 + 수면 확장 | 명상 중심 고수 |
| Sleep Stories 혁신 | 코스형 명상 |
| 셀럽 마케팅 | 애니메이션 콘텐츠 |

### 수익 모델

| 모델 | 가격 |
|------|------|

| 평생 이용권 | $399.99 |

### 성공 요인

1. Sleep Stories: 명상을 넘어 "수면"이라는 보편적 니즈 발견
2. 콘텐츠 품질: 셀럽 협업으로 프리미엄 이미지
3. B2B 확장: 기업 복지 시장 진출

## 3. 하루콩 (한국 - 블루시그넘)

### 기본 정보

| 항목 | 내용 |
|------|------|
| 출시 | 2021년 |
| 누적 다운로드 | 1,000만+ |
| 해외 비율 | 90% 해외, 미국 매출 50% |
| 운영 국가 | 180개국 |
| 개발사 | 블루시그넘 (대표: 윤정현, 27세) |

### 핵심 메커니즘

```
감정 선택 (아이콘) → 기록 → 패턴 분석 → 리포트 → 자기 인식
```

### 주요 기능

- 감정 아이콘: 웃는 표정부터 우는 표정까지 5단계 + 수백 종 형용사 아이콘
- **캐릭터 스토어: 디즈니 등 IP 콜라보**
	- 캐릭터 비즈니스가 강점..
- 감정 리포트: 월간/연간 분석
- 글 작성 불필요: 태핑만으로 기록 완료
	- 일기 앱이라 하여 긴 글을 작성할 줄 알았는데, 그렇지 않음

### 차별화 포인트

- "아이콘으로 손쉽게 표현하는 방식이 언어 장벽을 넘어 전 세계 이용자를 끌어들임"
- 극단적 간편함 (글쓰기 싫어하는 사람도 사용 가능)
- TikTok 바이럴 (감정 리포트 공유)

### 수익 모델

| 모델      | 내용                 |
| ------- | ------------------ |
| 광고      | 무료 사용자 대상          |
| 캐릭터 스토어 | 캐릭터 스킨 판매 (핵심 수익원) |
| 프리미엄 구독 | 광고 제거 + 추가 기능      |

### 성공 요인

1. 글로벌 퍼스트: 처음부터 다국어 지원
2. 극단적 간편함: "본질을 지키려 노력" (창업자 인터뷰)
3. 캐릭터 스토어: IP 콜라보로 수익 다각화

## 4. 무디 Moodee (한국 - 블루시그넘)

### 기본 정보

| 항목    | 내용                         |
| ----- | -------------------------- |
| 출시    | 2023년 3월                   |
| 다운로드  | 30만+                       |
| 해외 비율 | 80%                        |
| 수상    | 구글 플레이 2023년 최고의 앱 (한국/홍콩) |
| 평점    | 4.9                        |

### 핵심 메커니즘

```
감정 입력 → AI 분석 → 맞춤형 퀘스트 추천 → 수행 → 감정 개선
```

### 주요 기능

- 감정 태그: 다양한 감정 라벨링
- **퀘스트 추천**: "따뜻한 문자 다시 읽어보기" 등 맞춤 활동
	- 퀘스트가 보기만해도 따뜻해지는 퀘스트들 ( 사랑하는 사람 사진 찍기, 사진첩에서 가장 좋아하는 사진 찾기, 가장 좋아하는 연예인 사진 올리기 )
		- 괜찮은 것 같음. 불안/걱정 극복에 대한 컨셉으로 어플을 만들다해도 퀘스트에 대한 건 넣어볼 만 할 수도 있겠음
			- 불안/걱정을 어떻게 극복할 수 있을지? 행동으로 극복할지? 혹은 앱의 초기 컨셉대로 시간이 지나면 괜찮아질지.
			- 혹은 추후에 피드백 루프를 통해 걱정이나 불안을 낮추는 방향으로 갈지
			- -> 이 모든 것들을 포함하는 형태도 괜찮을 것 같음
- 트레이닝: 신경가소성 기반 가상 시나리오 훈련
	- 이 부분에 대해서 놀랐음
	- 정해진 시나리오 내에서 페르소나가 부여된 캐릭터들과 시뮬레이션을 진행하는데, 이상하게 위로를 해줘야하는 데 위로를 받는 느낌이 듬
	- 내 상황과 비슷한 페르소나와 대화를 하면 더욱 더 위로를 받을 수 있을 것 같음
- **AI 대화: 월 30회 (프리미엄)**
	- 이 부분은 서비스를 만들게 되면 반드시 넣어야할 항목
- 1,200개 모듈: 전문가 검수 심리치료 콘텐츠

### 하루콩 vs 무디

| 하루콩         | 무디         |
| ----------- | ---------- |
| 기록 중심       | 가이드 중심     |
| "오늘 기분 어때?" | "이런 활동 해봐" |
| 패턴 발견       | 행동 변화 유도   |
- 무디가 만들고 싶은 앱의 무드 훨씬 비슷함
	- 사용자가 들어와서 사용하는 것만으로도 힐링을 받을 수 있는 분위기
	- 이전에 **Abyssrium** 같은 앱이 주던 그런 느낌
	- 메이플스토리 "리스항구", "루디브리엄" 이 주는 그런 느낌을 줄 수 있으면 좋을 것 같음
- 좋은 BGM 이 필수여야 할 듯
	- 무디의 BGM 도 너무 좋음. 듣는 것만으로도 무디에게 위로 받는 듯한 숲 속에 들어와 있는 것 같음
	- 몽글몽글한 느낌 ( 딱 리스항구 )
- 대화 기능이 좋음
	- 친구가 하나 생긴 느낌
- 무디는 정신과적으로도 많은 공부를 한 느낌이 물씬남
	- 하루콩이 많은 사람들이 두루 쓸 수 있는 느낌. 무디는 치료에 조금 더 포커스를 맞춘 느낌
- 캐릭터도 잔잔한 느낌으로, 앱에 있는 것만으로도 따뜻함을 주는 느낌
	- Finch 와는 또 다른 느낌임. Finch 는 캐릭터가 활기차고 순수한 느낌. 무디는 나의 이야기를 들어주기 위해서 가만히 나를 보고 있는 느낌. 어디가지 않고 항상 제자리에 있어줄 것만 같은 느낌이다.
