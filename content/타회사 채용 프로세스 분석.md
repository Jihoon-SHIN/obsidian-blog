## 쿠팡

- 대상: L5 ~ L6 Software Engineer 기준 (frontend/backend/DE 동일)
- 참여 인원
    - Recruiter: 담당 리쿠르터
    - Hiring Manager: 최종 의사결정을 하는 주체
    - Engineer 1: 채용할 팀 엔지니어
    - Engineer 2: 다른 팀 엔지니어
    - Engineer 3: 다른 팀 엔지니어
    - Engineer 4 (Optional)
    - Bar Raiser (Director / Tech Lead): 다른 팀 디렉터 혹은 테크리드
- 프로세스
    - **Resume screening → Phone Interview → Live Coding Interview → Live Coding Interview → System Design Interview → Bar-raiser Interview → Debrief**
- 각 라운드 설명
    1. Resume screening
        - Recruiter 와 Hiring Manager가 서류를 보고, 진행 여부 결정
    2. Phone Interview
        - Hiring Manager와 간단히 핏을 보는 형태
        - 후속 인터뷰를 통과할 수 있을만한 사람인지 확인이 필요한 경우, 라이브 코딩 테스트로 진행되기도 함
    3. Live Coding Interview
        - 자료구조/알고리즘 중심의 코딩 테스트
        - 프론트의 경우 구현 위주의 문제가 나오기도 함
    4. System Design Interview
    5. Bar-raiser Interview
        - 경력와 컬쳐핏 중심의 질문들 (쿠팡의 경우 Leadership Principle)
        - 경력을 Deep Dive 하는 질문들이 많이 나옴. 왜 썼나요? 어떤 문제가 있었나요? 어떻게 결과를 측정하셨나요? 다른 대안은 뭐였나요? 등등
    6. Debrief
        1. 참여한 면접관들 모두 + Hiring Manager가 모여 채용 여부를 논의하는 단계
        2. 인터뷰 라운드마다, Greenhouse(채용 관리 서비스)에서 다음을 작성
            - 결과: **Strong No / No / Yes / Strong Yes** 이유: (구체적으로)
        3. 총 4~5개의 평가 결과들을 담당 면접관이 각각 설명하고, 최종적으로는 Hiring Manager가 채용 결정을 함
            - 보통 만장 일치에 가까울 때만 채용이 결정됨
            - 만약 뽑고 싶은데 결과가 조금 아쉬울 경우, 부족했던 부분의 인터뷰를 한번 더 진행하기도 함

## 토스

- 대상: Frontend Engineer, Backend Engineer
- 참여 인원
    - Recruiter
    - Engineer 1
    - Engineer 2
    - Engineer 3
    - Engineer 4
    - HR / C level / Tech Lead: 컬쳐 면접 볼 자격이 있는 사람 중 1
- 프로세스:
    - Frontend: **Resume screening → Take-home assignment → Tech Interview → Culture Interview**
    - Backend: **Resume screening → Tech Interview → Tech Interview → Culture Interview**
- 각 라운드 설명
    1. Resume screening
        - 1차적으로 Recruiter가 이력서를 스크리닝 하고, 3명의 개발자에게 이력서 평가를 요청
        - 2명 이상이 찬성 시 면접 진행
    2. (Frontend) Take-home assignment
        - React 기반 구현 과제가 주로 나옴
        - 3명의 개발자가 과제를 평가 후, 2명 이상 찬성 시 이후 프로세스 진행
    3. Tech Interview
        - 과제 혹은 경력 기반의 기술 면접, 코딩 테스트는 없음
        - 2~3 명의 개발자가 면접관으로 같이 참여, 면접 후 같이 논의해 이후 프로세스 진행 여부 결정
    4. Culture Interview
        - 토스의 경우 근속년수, 직책 등에 따라 컬쳐 인터뷰를 볼 수 있는 권한이 주어짐
        - 보통 HR / C level / Lead 등등
        - 해당 라운드에서 상당히 많이 떨어짐
